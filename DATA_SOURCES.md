# Data Sources & Attribution

This document outlines the third-party repositories and datasets used to construct the problem metadata for Company Wise DSA.

## Dataset Scope
The production dataset contains normalized metadata, including:
- Question title
- LeetCode URL
- Difficulty
- Company associations
- Topic associations
- Relative frequency signals
- Source provenance

**Important Scope Limitation:** This application does NOT distribute LeetCode problem statements, solutions, editorials, or test cases. Only titles, basic metadata, and organizational tags are indexed to provide a searchable frontend.
